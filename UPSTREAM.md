# Upstream

What tosijs-3d is waiting on in other repos is tracked on the **virta board**
as cards tagged `notes:upstream` (`virta ls "project:tosijs-3d notes:upstream"`).
A card tagged `fixed-upstream` means the owner fixed it and our workaround has
not yet been walked. An ask of another repo that is on the board is a task in
THAT project; for repos that are not, file a GitHub issue there and add a card
here linking it.

The rule has not changed: file, don't fix — never edit the owning repo from
here. See `tosijs-coding-practices/practices/cross-project.md`.

The table this file used to hold is preserved at the end of `DECISIONS.md`.
