Biped Playground

A place to run around and murder things in. One call returns a whole arena — ground, light, cover, crates, a catwalk and something to shoot — as ordinary scene children, so it composes into any demo rather than being one.

// Adjustments for `name`'s class (a character from before grips were per
// class kept them per item).
const keptFor = (name) => {
  const kept = gripsKept()
  const c = holdClassOf(name)
  const own = kept[c] ?? kept[name]
  return own ? { ...kept, [c]: own } : kept
}
const gripFor = (name, side) => {
  const { scale, ...grip } = holdGrip(name, keptFor(name), undefined, side)

}

// THE INVENTORY says what you hold: the loadout (a button on the system bar)
// starts with the pistol on your hip and the rest in the bag. Whatever is in
// your right hand is what the launcher carries; a gun in hand is up (aim and
// fire), anything else is held with the weapon down. The weapon button draws
// from the hip or back, or puts away what is in hand; dragging works too.
//
// AND SOME OF IT IS LYING ON THE GROUND. Walk up and press E (interact) to
// pick a thing up into your bag; drag anything out of the loadout onto drop
// and it lands at your feet. A world item is a KIND: picking it up makes an
// item of that kind, so items are looked up by kind, never by id.
const loadout = demoLoadout({
  catalogue: WEAPONS,
  equip: { right_side: 'Pistol' },
  // The yard's two chests are holders in the same inventory.
  holders: { 'gate chest': {}, 'yard chest': {}, shop: { purse: { gold: 200 } } },
  price: (item, from) => shopPrice(item, from),
  // Money, written as the game writes it: `12 gold` (a label after the
  // amount; `€` or `$` would go before it).
  purse: { gold: 25 },
  currencies: [{ id: 'gold', label: 'gold' }],
  // Dropped is THROWN: 3 m off to the right front, low, and where it lands it
  // makes a noise, so it is how you lure the enemy away.
  handleDrop: (item) => {
    const node = hero.entries?.rootNodes[0]
    if (!node) return
    const f = node.forward
    // 45 degrees right of facing.
    const d = { x: (f.x + f.z) / Math.SQRT2, z: (f.z - f.x) / Math.SQRT2 }
    const p = node.position
    const thrown = pickup(item.kind, p.x + d.x * 0.4, p.z + d.z * 0.4)
    thrown.y = 1.1
    hero.owner?.append(thrown)
    requestAnimationFrame(() =>
      thrown.toss({ x: p.x + d.x * 3, z: p.z + d.z * 3 }, { height: 0.3, seconds: 0.45 })
    )
  },
})

const useRounds = (kind, n) => {
  let got = 0
  for (const i of heroItems().filter((i) => i.kind === kind)) {
    const take = Math.min(n - got, i.qty)
    if (take <= 0) break
    loadout.inv.move({ item: i.id, qty: take, to: null })
    got += take
  }
  return got
}

const trades = {}
let trading = null
const endTrade = () => {
  if (!trading) return
  const { chest, done } = trading
  trading = null
  tradeBox.hide()
  if (chest) chest.open = false
  // A trade opened from a conversation hands back to it.
  done?.()
}
// Closed with its own ×, it ends the same way.
tradeBox.addEventListener('paneltoggle', (e) => {
  if (!e.detail.open) endTrade()
})
// One trade per holder, made the first time; a shop's has prices.
const openTrade = (holder, { chest = null, title = 'Chest', at, price, done } = {}) => {
  trades[holder] ??= tradePanel({
    inv: loadout.inv, carry: createCarry(),
    mine: BAG, theirs: stock(holder),
    titles: { mine: 'you', theirs: holder },
    // The shopkeeper, in a sentence ("he can't offer more than 200 gold").
    they: holder === 'shop' ? 'he' : undefined,
    price,
    // How many, on a stack.
    decorations: (it) => (it.qty > 1 ? { badge: `×${it.qty}` } : undefined),
    // Ammo goes a box (24 rounds) at a time, not the whole stack.
    moveFor: (item, from, to) => {
      const it = loadout.inv.doc.items[item]
      return AMMO.includes(it?.kind) ? { item, qty: Math.min(24, it.qty), to } : { item, to }
    },
    handleDone: endTrade,
  })
  trades[holder].begin()
  tradeBox.title = title
  tradeBox.svg = trades[holder].svg
  tradeBox.show()
  trading = { chest, at: at ?? (() => chest?.mesh?.position), done }
}

// Babylon, from sceneCreated (lowercase: see the doc transpiler's all-caps rule).
let babylon = null
const wearGear = (h) => {
  if (!babylon) return
  const skeleton = h.entries?.skeletons?.[0]
  const left = kindOf(slotsNow().hand_left.holds)
  const back = kindOf(slotsNow().back.holds)
  const key = `${skeleton?.uniqueId}|${left}|${back}`
  if (!skeleton || key === gear.key) return
  for (const n of gear.nodes) n.dispose()
  gear = { key, nodes: [] }
  const mount = (kind, where, g) => {
    const at = mountNode(skeleton, where)
    const node = at && weapons.instantiate?.(kind, { canonical: true })
    if (!node) return
    node.parent = at
    const d = Math.PI / 180
    const turn = babylon.Quaternion.FromEulerAngles(g.rx * d, g.ry * d, g.rz * d)
    const grip = (heldGrip(node) ?? babylon.Vector3.Zero()).scale(g.scale).applyRotationQuaternion(turn)
    node.position.set(g.x - grip.x, g.y - grip.y, g.z - grip.z)
    node.rotationQuaternion = turn
    node.scaling.setAll(g.scale)
    gear.nodes.push(node)
  }
  // The left hand's thing on its LEFT mount (a shield strapped to the
  // forearm, a dagger in the hand), its grip mirrored if set for the right.
  // In the hand or on the forearm: the class's own place unless the
  // character wears it elsewhere (a buckler in the fist).
  const place = left && placeIn(left, gripsKept())
  if (left) mount(left, holdMount(holdClassOf(left), 'l', place), holdGrip(left, keptFor(left), undefined, 'l', place))
  if (back) mount(back, STOW_MOUNT, stowGrip(back, gripsKept()))
}
// Each gun keeps what is in its magazine while it is put away.
const magazines = {}
let inHand = null
const hold = (h) => {
  const id = inRight()
  const kind = kindOf(id)
  const w = kind ? WEAPONS[kind] : null
  // Any weapon in hand is the launcher's model, a sword too (it is shown, not
  // fired); only a gun has a magazine to keep.
  if (w && id !== inHand) {
    if (inHand && WEAPONS[kindOf(inHand)]?.fire) magazines[inHand] = gun.loaded
    inHand = id
    // A bow rides the LEFT hand's socket (hold-grip's mount for its class).
    const side = holdMount(holdClassOf(kind)).side
    const socket = side === 'l' ? 'left-hand' : 'right-hand'

    if (w.fire) gun.loaded = magazines[id] ?? w.fire.ammo
    gun.reloadModel()
  }
  // The clips the raised weapon plays (a new hero, after a respawn, too).
  if (w?.fire) h.setAimClips(holdClassOf(kind) === 'bow' ? AIM_CLIPS.bow : AIM_CLIPS.pistol)
  h.holdingWeapon = w != null && w.fire == null
  h.setGunplay(w?.fire != null)
}

Two modes, and the right bumper is the switch. You start with a pistol on your hip and the rest of Tonio's weapons in the bag: open the loadout from its button on the system bar and drag any of them onto a hip, your back or your right hand. With the weapon down you are walking: R sprints. Press right shift (middle click, or the right bumper on a pad) and you draw what is on your hip (or back), and if it is a gun it comes up: now R fires, Q aims down the sights, and a ring shows where the round will actually land, sinking as the range grows because it is the real ballistic arc rather than a dot in the middle of the screen. You cannot sprint with the gun up, which is why the trigger is free to do both jobs. Each gun fires its own way (the SMG fast, the rocket launcher slow and heavy). A blade, the spear or the buckler takes a guard (UAL's Sword_Idle) and R swings it (Sword_Attack, played through; held, it swings again). Press the bumper again to put away what is in your hand. Only the right hand is drawn.

Ammo. A gun holds a magazine (the pistol 12, the SMG and rifle 30, the rocket launcher one) and reloads from what is in your bag: J (d-pad left) reloads, and an empty gun reloads itself when you pull the trigger. The panel at the bottom of the view shows your health, what is loaded and what is left; drag it wherever you like. You start with 36 pistol rounds; ammo boxes lie about, and each gun keeps its own magazine while it is put away.

Health. A potion (30) and a heart (60) lie about: walk up and press E. At full health they stay where they are.

A shop, and someone to talk to. The mannequin behind the counter to your right is a shopkeeper: press E at the counter and he talks. His lines and your replies appear in a balloon over his head; click a reply or press its number. Ask what he sells and his stock opens beside your bag, with prices; when you close it he carries on. Ask whether he needs anything, then bring him the potion from the gate chest. Walk away and the conversation ends. In the shop, drag things across either way (ammo goes a box of 24 at a time); the line under the lists says whether you pay or receive and how much. Deal settles, cancel puts it all back. It sells at an item's value and buys at half. You have 25 gold.

Things to pick up. A rifle, a sword and a buckler lie in front of you: walk up and press E to pick one up (you kneel for it), and it goes in your bag. Drag anything from the loadout onto drop and you throw it: it lands 6 m ahead with a clatter the enemy hears.

A locked yard. Behind the start is a walled yard with a locked door. The key is in the chest beside it: press E and the chest opens with what is inside next to your bag; take what you want and leave the rest. The key opens the door, and the chest inside holds the rocket launcher, the big sword and rockets.

Something hunts you. Two enemies: one stands guard beyond the cover line with its back to you, one walks a loop near it. Neither can see the start, the shop or the things lying about, so you can try those in peace; the fight starts when you cross toward the cover line. Each is oblivious until it notices you: anywhere in front of it within 25 m (cover hides you; where you start, neither can see you), or within 10 m behind it. Crouch (left shift) and those drop to a third, so you can creep to 3 m behind one. A shot is heard 25 m off. Noticed, it chases and swings when it reaches you; lose it and it searches where it last saw you, then goes back to its post or its route. Throw something (drop it from the loadout) and it goes to look where it landed. It is deliberately dumb: it runs to where you WERE, so a sidestep beats it. Bullets hit where they land: a head shot does two and a half times the damage, a limb half: one pistol round to the head puts one down, three to the body, five to the arms and legs. Add #debug to the page's address and Perf Stats, in the settings panel, says what each is doing.

Something shoots back. A turret past the cover line fires slow shells at you (four hits kill); each hit staggers you, and out of its sight you heal. Crouch behind the low wall or duck behind a pillar.

Falls hurt. Jump off the catwalk and you land hard (a roll that holds you a moment); walk off the top of the tower and you die where you land, then respawn at the start.

WASD moves, arrow keys look, space jumps, left shift sneaks, E interacts, Y switches between third and first person. On a pad the actions are on the right hand: A attacks, B uses (doors, chests, the lift, picking up, talking; with the weapon up it ducks instead), clicking the right stick jumps, and clicking the left stick sneaks. Hold D-pad up to reach the system bar with the pad: left and right step along it, B opens a panel, up and down cycle through its controls, left and right move sliders, B presses. Hold up in a panel to close it, and on the bar to go back to playing; a chest's panel closes straight back to playing. On the keyboard, Tab steps through an open panel.

Play as a character of your own. Make one in the character builder (or press make your own character… in this page's settings panel, the goggles on the bar) and press play in Biped Playground there, or save it and pick it from character here. It takes the hero's place where he stands, holding what you held. Characters belong to the browser that made them.

Things to try: put the pistol in the bag and try to raise it (nothing to raise), pick up the rifle and drag it into your hand (it comes up, and both hands are taken); carry a sword on your hip and draw it; swim and dive in the pool; climb the crates onto the catwalk; shoot from behind the low wall and watch the ring disappear behind it until you stand; walk the cover line and compare the railing with the wall beside it.

Using it

It is a list of scene children, so it spreads into a scene of your own:

b3d(
  { style: 'width:100%;height:100%' }, // your own scene options
  ...playground(),
  inputFocus(hero)
)

Every piece in here exists to exercise something the biped can do, and the arrangement is a test you walk around in rather than one you read.

What each part is there to prove

exercises
the low wall (1.1m) crouch cover — stanceFor says crouch, and crouched you are fully hidden
the pillars cover you can lean past on either side — peekSide returns both
the bunker (an L) cover from a threat the wall does not face, which is why shelterFrom searches an arc
the railing cover that ISN'T. Same height, same distance, gap underneath. The one everybody's first implementation gets wrong
the crate steps (0.4 / 0.9 / 1.6m) the band between a step and a wall — mantle
the catwalk verticality, a firing position, and something to fall off (a hard landing)
the targets something to murder
the pool swimming, diving (aim down and swim), surfacing, and a shelving ramp to walk in on slowly

Everything is an ELEMENT, deliberately

No sceneCreated hook, no el.make calls, no imperative build step — the playground is a list of scene children, which means a caller can splice it, override a piece, or take half of it. It also means the whole arena is already in the shape a data format would want: "the standard arena, plus the thing I am showing you" can be one line of data.
