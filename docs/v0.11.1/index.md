# 0.11.1

<!--{ "parent": "CHANGELOG", "order": 9988999 }-->

## Fixed

- **The glass gamepad draws on your site** (0.11.0 docs review). Its default art was fetched from `/gamepad-left.svg`, `/gamepad-right.svg` and `/gamepad-top.svg`, which our doc site serves from `static/` and the package does not ship, so on an adopter's site the fetches 404'd and `gamepad` mounted nothing. The art is now built into the library (`src/gamepad-art.ts`, generated by `bun run dial-art`, as the compass and watch are); a cluster `url` of your own is fetched as before.
- **The XR reticle draws on your site**: `xr-reticle="on"` fetched `/reticle.svg`, which only our doc site serves. It is built in now, like the gamepad.
- **The crowd's skinned baseline loads on your site**: `skinnedUrl` defaulted to `/omnidude.glb`, which only our doc site serves. It now defaults to omnidude on the CDN (`assetUrl('tonio/omnidude/omnidude.glb')`).
- **The docs are reorganised** (0.11.0 docs review, `reviews/0.11.0-docs-review.md`). About 56 helper pages are folded into the page that uses them (the water's shore, caustics and normal map into [b3d-water](/b3d-water/), the movement model into [b3d-biped](/b3d-biped/), the gamepad sources into [virtual-gamepad](/virtual-gamepad/), and so on); their old URLs are gone. Pages state what is true now, without history. Design essays moved to the design docs, and Tonio's remarks that decided things are on [Design notes](/design-notes/). Attribute tables are complete for `<tosi-b3d>` (35), the biped (33), water, skybox, planet, clouds, lamp, launcher, turret, radar, glass gamepad and others. The changelog is one page per version, and it and Migration are under [Upgrading](/upgrading/). No code changed.
- **Doc fixes from the 0.11.0 docs review** (`reviews/0.11.0-docs-review.md`): b3d-aircraft's `missileSpeed` default is 90, not 55; b3d-panel had two `flat-frame` rows (merged) and its methods and events sat under Attributes (own heading now); b3d-controllable's example used a field only the aircraft has (it now turns `ry`); svg-texture said a theme font reaches a texture only if installed, and now points at `registerSvgFont`; the formations demo used `orbitCam`'s deprecated radians; b3d-cloud-deck's "first pass, not tuned" section listed problems already fixed; b3d-radar-blip's page ended in a stray `#`.
