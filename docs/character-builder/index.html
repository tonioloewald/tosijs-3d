character builder

Make a person, and watch them walk. The first steps of the character creator (CHARACTER-DESIGN.md): MakeHuman's CC0 body (human-pack), reshaped by sliders for gender, age, muscle, weight, height and ancestry (human-morph), with UAL's skeleton placed from its own joint cubes (human-rig) so it plays UAL's clips at any shape.

          built.root.parent = stand
          clipLow = null
          ground()
          el.register({ meshes: [built.mesh, ...face.meshes] })
          if (walker.stubble.value > 0) measureStubble()
          paint()
          read = readSkeleton(built.skeleton, built.root)
          play()
          busy = false
          if (again) { again = false; rebuild() }
        }
        await rebuild()
        el.setLoading(false)
        walker.clip.observe(play)
        walker.paused.observe(() => (walker.paused.value ? playing?.pause() : playing?.play(true)))
      },
    },
    b3dSun({ timeOfDay: 16.5, shadowTextureSize: 2048, shadowMaxZ: 20, shadowNormalBias: 0.008 }),
    b3dLight({ intensity: 0.5 })
  )
)

tosi-b3d { width: 100%; height: 100%; }

Open the settings (the owl): the body sliders reshape it while it walks, since every body carries its own joints. The skin weights are bone heat's, worked out from the mesh once when the page loads. The eyes (human-face) follow the camera, and the hair (human-hair) is Quaternius' CC0 hairstyles, made for another head and fitted to this one.

Tailor cuts a garment of your own out of the body. Draw the outline opens the front view beside the panel; click out an outline over it (you draw the character's left, on your right; the other side is its mirror), and the skin inside it, front and back, becomes cloth. A rectangle from the waist to the ankles is a pair of trousers. Click the first point to close a shape, drag a point to move it, press an edge to add one (garment-cut).

A cut is a start, not a finished garment: export it (glTF or OBJ, the garment and the body it was made on), shape it in Blender (a collar, pockets, its own UV unwrap), and import it back. It is bound to the body again by its shape, so it fits every body like the rest (garment-file). Or export the body alone and model a garment from nothing beside it. In Blender, tick Include → Custom Properties when exporting, so the file still says which body it was made on.

New objects come in as part of the garment. Anything hard (a knee pad, a plate, a visor) gets a rigid custom property so it keeps its shape instead of bulging with the body under it (proxy-rigid).

Its surface is made in Blender too: the garment's material comes back with its base colour, normal, roughness and alpha maps, and fabric as made with recolour at 0 shows it untouched. Recolour above 0 tints the base colour map, read as grey.

Hide other clothes shows the garment on its own. Name it, pick its slot and save as an option: it is kept in this browser and becomes a choice in that slot like MakeHuman's own, with the fabric and colour it was saved with. A saved cut can be edited again from its outline; forget removes it.

humanBody

humanBody(scene, pack) draws a pack's body as one unrigged mesh, and update(positions) reshapes it in place: for a body that only needs to be looked at.

The pack is RIGHT-HANDED (as OBJ and glTF are), so the body sits under a container that mirrors it the way glTF's __root__ does, and stands with its feet at the container's origin. Move the body by moving root. The mesh keeps every vertex the targets move (helpers and joint cubes too), but draws only the body's triangles.
