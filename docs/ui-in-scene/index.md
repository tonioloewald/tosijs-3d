# In the scene and XR

<!--{"order": 400, "parent": "ui"}-->

**Putting an interface in the world.** [b3d-panel](/b3d-panel/) pins a panel to
a part of you (your wrist, your view, the vehicle) and shows it when you look.
[b3d-svg-plane](/b3d-svg-plane/) and [svg-texture](/svg-texture/) are the layer
underneath: any SVG, live, on any surface.
