# World Sim

<!--{"order": 110}-->

**A world that something else can drive.** The simulation holds the state and
resolves what physically happens; an outside driver (a story engine, a script,
a test) reads it and steers, and neither calls the other. Read the
[contract](/world-contract/) first, then the [store](/world-store/) that
implements it and the [view](/world-view/) that draws it.
