# Weather and clouds

<!--{"order": 30}-->

**Cloud, wind, storms and the things that drift in the air.** One idea runs
through all of it: weather is something every component asks about *where it
is*, so a storm can be over there and not here. Start with the
[cloud deck](/b3d-cloud-deck/) for an overcast you can fly through, add a
[weather cell](/b3d-weather-cell/) for a region that differs, and
[lightning](/b3d-lightning/) follows the storminess. [b3d-ambient](/b3d-ambient/)
is the small stuff: motes, leaves, bubbles.
