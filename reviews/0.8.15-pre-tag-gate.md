## Majors (all verified)

1. **Water reflections are wrong in a headset.** `src/b3d-water.ts:389`, correctness, severity uncertain.
   - The new `reflectionRefresh` sets `refreshRate` on both WaterMaterial render targets. Babylon advances that counter once per rig camera, so it counts eye-passes, not frames.
   - Rate 2 (medium tier) draws the left eye only, every frame, and saves nothing. Rate 3 (low tier, which a standalone headset gets) alternates eyes every 1.5 frames.
   - The skipped eye samples a reflection drawn with the other eye's view. This is a stereo regression from 0.8.14 on the device the change targets.
   - Confirmed by code trace and matched by the lens's emulator log. Not checked on a device; the visible size of the error is unmeasured. Flat rendering is unaffected.

2. **Clumping makes every scatter rebuild 4-5x slower on the main thread.** `src/scatter.ts:443`, efficiency, severity uncertain.
   - Reproduced independently, warm ground cache, 0.8.14 vs HEAD:

     | Budget | 0.8.14 | HEAD |
     | --- | --- | --- |
     | 2000 (default) | 7.0 ms | 33.7 ms |
     | 8000 | 20.9 ms | 118.3 ms |
     | 20000 | 84.6 ms | 330.4 ms |

   - With `clump: 0` HEAD returns to the old cost, so the whole delta is `clumpWeight`: it re-hashes the group string per candidate per rule, runs even when suitability is 0, and is not shared across rules with the same group.
   - The cost is paid on every `follow` rebuild (each 225 m of camera travel at defaults). The Quest multiplier is an extrapolation.

3. **The CHANGELOG's migration note is false as written.** `CHANGELOG.md:71`, docs. Absorbs the correctness finding on `NATURE_KIT_RULES` (`src/scatter.ts:839`).
   - It says naming a `url` "keeps the old behaviour". It does not: `NATURE_KIT_RULES` now carries procedural `rock:` rules at a different scale, every rule clumps at 0.85, and rocks are now suppressed on volcanic provinces.
   - The rock suppression is disclosed nowhere, and the `suppress` JSDoc at `src/scatter.ts:140` still says a lava field gives "1 to rocks".

4. **The procedural-rock page invites an inside-out mesh.** `src/procedural-rock.ts:13`, docs, severity uncertain.
   - `rockGeometry` indices wind counter-clockwise (measured: 320 of 320 triangles). The decorator has to swap them before handing them to Babylon.
   - Neither the page nor the `RockGeometry` type mentions winding, and the page's only example leads straight to the bug.

5. **The new decorator default silently empties some consumers' scatter on a patch update.** `src/b3d-decorator.ts:261`, blast radius, severity uncertain. Absorbs the two "silently skipped model name" findings (correctness minor, unverified; docs minor, verified).
   - Custom rules with Kenney names and no `url` now run against the Quaternius library. Every name misses, `_model()` returns null, nothing is placed and nothing is logged.
   - A self-hoster who mirrored only the Kenney kit gets a 404 and one warning.
   - `Migration.md` has no 0.8.15 entry. The CHANGELOG ⚠️ block does name the remedy, and the remedy works.

## Minors

- **Scatter docs contradict themselves on the budget** (verified, docs). `src/scatter.ts:26-28` and `:56-57` say the budget is always met; `:30-34`, the code and the CHANGELOG say it is a ceiling. `src/b3d-decorator.ts:5`, `CLAUDE.md:639` and the comment at `src/scatter.ts:469` are also stale.
- **Two `sink` options, and the page does not say which governs** (verified, docs). The decorator's placement exactly cancels the geometry's own `sink`, so tuning `ROCK_KINDS.*.sink` does nothing for a decorator rock; `ScatterRule.sink` alone buries it.
- **Vegetation roles are a uniform branch** (verified as plausible, efficiency). The terrain shader now contains `discard`, and leaf and bark fragments run the whole ground chain. No cost has been measured on any device.
- **Perf Stats "Occlusion: on/off" reports the setting, not whether occlusion is running** (unverified, correctness). `src/tosi-b3d.ts:3333`. Also the Land and Sky select desyncs from the button, and a comment is misplaced.
- **Decorator picks default rules from `url` truthiness but its library from the resolved URL** (unverified, correctness). `src/b3d-decorator.ts:183`. Naming the default library explicitly selects Kenney rules against it.
- **Several behavioural fixes have no test that fails without them** (unverified, correctness): `row3d.setHost`, `menuWidth`, water budget resolution, the shadow twin's unique geometry, the `rules` getter fallback, `roleFor` in the element, the occlusion button.
- **Decorator budget is a fixed 2000 on every tier** (unverified, efficiency). `src/b3d-decorator.ts:140`. The default library is about 1.8x the vertices of the old one.
- **`NATURE_ROLES` applies to every library and keys on generic material names** (unverified, blast radius). `src/scatter.ts:719`. A third-party GLB with a material named `White` or `Wood` gets it replaced by a flat StandardMaterial.
- **`row3d`'s host fix is one instance of a class** (unverified, blast radius). `src/widgets3d.ts:1431`. Any container that does not forward `setHost` degrades `select3d` silently.
- **New public surface appears only in the CHANGELOG** (unverified, docs): biome roles and seasons, `headsetDevice`, `ScatterRule.sink`, `ROCK_RULES`, `NATURE_RULES`, `roleFor`, `rockNames`, `ROCK_KINDS`, `clumpAt`, `autoClumpSize`.
- **No lane executed the live examples this release touched** (unverified, docs). Land and Sky, decorator, water and terrain pages were not mounted.
- **The ⚠️ decorator change is not in `Migration.md`** (unverified as a separate finding; the gap itself was confirmed under major 5).
- **The ePub 404 is a tosijs-ui defect worked around locally** (unverified, blast radius). `site.config.ts:103`. No upstream card exists.

## Completeness gaps (not reviewed; none drives the verdict)

- **Committed `docs/` and `dist/` were never checked against source.** Nobody ran a stopped-server `bun run build` followed by `git status`, or imported the packed tarball under plain Node for the new modules. This is the highest-value missing check before the tag.
- **HEAD is unpushed**, so nothing remote has seen the artifact that will be tagged.
- **Adopters were not traced.** Nobody grepped manta-recon, tosijs-3d-ensemble or Ariosto for `b3dDecorator`, `scatterPlacements`, `NATURE_KIT_RULES` or `volcano()`. Same seed now gives a different layout, which matters to anyone who persisted or tested placements.
- **CDN asset.** The default now depends on `quaternius/libraries/nature.glb`. It returned 200 for one lens. Unchecked: whether the deployed GLB's model and material names match `NATURE_RULES` and `NATURE_ROLES`, the offline path, and Quaternius licence and attribution for a default.
- **Headset budgets when flat.** `isStandaloneHmd` is a heuristic that may also match Android phones and tablets and lower their flat quality. The forced `quality=` path is claimed only in a comment. Nothing was measured on a Quest.
- **Water beyond stereo.** Reflection lag at medium tier (now refresh 2 at 512 px on ordinary laptops) and the stability of `getRenderTargetTextures?.().data` across the ^9 peer range are unchecked.
- **Shader changes were never executed.** About 175 lines of new GLSL: no compile check on mobile precision, no check against the projected-occlusion, cloud-shadow and caustics plugins on the same material, no look at the shadow path for dropped leaves. Needs flat screenshots of Land and Sky across seasons with shadows on.
- **`measureCost()` and the decorator page's cost claims** were not re-checked against the new default library.
- **New barrel exports had no dx or idiom pass.** Open questions: bare common nouns (`roleFor`, `clumpAt`), two near-identical role types (`DecorationRole`, `BiomeRole`), and whether `seasonOf` living in `biome-plugin.ts` puts a pure function behind Babylon.
- **Schemas.** `waterSchema.textureSize` minimum moved from 64 to 0, so 1 to 63 now validates. `roles` and the new meaning of an empty `url` are not expressible. Ensemble's consumers are unchecked.
- **`volcano()` rim value changed from 0.5 to 0.25.** The test was edited to match; downstream readers (scatter suppression, province-climate, weather) were not traced.
- **`@resvg/resvg-js`** is a new native devDependency with no reference in this repo's own code. Whether it is needed here is unverified, and nobody opened the new ePub that is now published.
- **UI fixes were reviewed as diffs only.** The `row3d` host change and wider menus near a panel edge were not rendered, though both are checkable flat in a minute.
