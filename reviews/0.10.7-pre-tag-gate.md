## Fix before the tag

- [ ] **Re-adding a removed `<tosi-b3d>` freezes the scene** (correctness, verified), `src/tosi-b3d.ts:2530`.
  - Cause: `_teardown` nulls `_sceneBar` but keeps `_sceneBarButtons`. On re-add the shadow buttons are the same elements, so `same` is true and the rebuild is skipped. `this._sceneBar!` is then null and `bar.count` throws inside `_update` → `_updateFlatPanels`. Babylon queues the next frame only after `_processFrame` returns, so the render loop dies. This is the default `flat-ui`.
  - Fix: reset `_sceneBarButtons = []` in `_teardown`, or rebuild whenever `_sceneBar == null`. Consider also clearing `_sysPanel` and `_modals`, which hold closers into the disposed scene.
  - **Clears when:** a test that tears down, re-adds, and calls `_sceneToolbarSpec`/`_updateFlatPanels` fails with the fix reverted. Alternatively, a driven remove-then-re-add in a private haltija instance shows the bar and a running scene.
- [ ] **A system-bar panel without a JS `svg` is dropped silently** (docs, verified), `src/tosi-b3d.ts:2356`.
  - Cause: the CHANGELOG, the system-bar page and the b3d-panel Pins section all show attribute-only markup (`preset="system-bar" icon=… title=…`). `_systemSpecs` requires `s.svg != null`, and the rig-panel and flat-`both` paths exclude `system-bar`. The panel appears nowhere and nothing warns.
  - Fix: either warn once ("system-bar panel needs an `svg` (JS property); ignored") or fall back to the title/url placeholder card. In both cases, say on the `preset` row and in Pins that `svg` is required.
  - **Clears when:** a test that declares an svg-less system-bar panel and asserts it gets either a warning or a button fails with the fix reverted.
- [ ] **`flatUi` / `flat-ui="dom"` is undocumented** (docs, verified), `src/tosi-b3d.ts:700`.
  - Cause: this is the escape hatch for the release's default change. It has no row in the tosi-b3d attribute table, and its `attributes.txt` line is empty (so is `clearColor`'s beside it). Any value other than `'dom'` silently means `'scene'`.
  - Fix: add the row: `'scene'` is the default; `'dom'` restores the HTML corner buttons, settings panel and pause as before 0.10.7. Warn once on any other value.
  - **Clears when:** after the prebuild, `grep flatUi static/attributes.txt` shows the default and the description, and a test that sets `flat-ui="html"` and expects one warning fails with the fix reverted.
