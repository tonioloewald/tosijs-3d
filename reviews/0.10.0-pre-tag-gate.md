## Blocker

**B1. The request is "cut a patch", but the diff is the 0.10.0 breaking release** (verified by three lenses; deduped). `CHANGELOG.md:9`, `package.json:3`.

- The diff removes every `onX` callback option, trigger `onEnter`/`onExit`, manipulator `handleChange`/`handleCommit`, `generateGalaxy` and `getStarSPS`. `new MersenneTwister()` without a seed throws, `WorldStore` queries return copies, and the conformance kit requires `chooseOption`.
- CHANGELOG heads it "0.10.0 (unreleased)"; Migration.md has "0.9.0 → 0.10.0"; `handler-of.ts:68` warns "removed in 0.10". `package.json` and `llms.txt` still say 0.9.0 (normal pre-bump state).
- `tosijs-3d-ensemble` declares the peer range `^0.9.0`, which accepts 0.9.1 and excludes 0.10.0. Its own devDependency and manta-recon pin exactly `0.9.0`, so the exposure is the peer range and any outside caret user.
- This rests on the repo's own rule (RELEASING.md:83-84) and on the patch-by-default memory, which carves out breaking changes.

**Clears with:** tag as 0.10.0. Re-review scope is Tier 0 only (version in `package.json`, `llms.txt` and the CHANGELOG heading agree). A true 0.9.x patch would have to be cut from a branch without b1299e47 and be2e4463.

## Fix before the tag (verified majors)

- [ ] **M1. `nearFirst` recomputes both sort keys inside the comparator** (`src/draw-order.ts:45`; efficiency). Babylon now sorts every opaque submesh of group 0 on every camera pass, and the comparator calls `getMesh()`, `getBoundingInfo()` and reads the camera position twice per comparison. Measured on NullEngine (reviewer and verifier agree): 200 submeshes 0.20 ms, 1000 1.5 ms, 3000 5.7 ms per sort, against 0.03 / 0.18 / 0.70 ms with keys computed once. It runs per eye and per water target. Not measured on a device.
  - Fix: compute the key once per submesh per pass (stamp with `scene.getRenderId()`) and compare numbers.
  - **Check that clears it:** a test that counts key computations for one sort of N submeshes and expects N, not N log N; it fails with the fix reverted.
- [ ] **M2. The attribute index gives `<tosi-b3d-ground>` the box's defaults and descriptions** (`static/attributes.txt:778`, `attributes.json`; docs). Index says `size = 1`, `width = 0`, `height = 0`, `color = '#ff0000'`; source says size 0, width 4, height 4, `'#888888'` (`src/b3d-primitives.ts:414-421`). `tableRows()` in `bin/attribute-index.ts` keeps one map per doc comment, so the first table on a two-table page wins. The file ships and README sends agents to it first. Check the sphere rows in the same fix.
  - **Check that clears it:** an invariant in `attribute-index-invariants.test.ts` that an indexed default equals the element's `initAttributes` value; it fails on the current index.
