## Fix before the tag (verified majors)

- [ ] **Ground vehicle swaps `scene.activeCamera` during an XR session** (correctness, verified). File: `src/b3d-ground-vehicle.ts:263`.
  - **Defect:** `setupFollowCamera` calls `owner.setActiveCamera(this.chaseCamera, …)`, which has no XR guard, instead of `owner.setGameplayCamera`.
  - **How it happens:** entering a car with X in VR (`handleGainFocus`), or a focused vehicle's model finishing loading mid-session (line 482).
  - **Effect:** the view is taken off the WebXRCamera, so the headset goes blank.
  - **Fix:** call `owner.setGameplayCamera(this.chaseCamera, { attach: false })`, and skip building and aiming the flat chase camera when it returns false. Alternatively, return early on `owner.xrActive`, as the biped and aircraft do.
  - **Check that clears it:** a `bun run xr /b3d-car/` script that focuses the car while `xrActive` and asserts `scene.activeCamera` is still the WebXRCamera. It must fail with the fix reverted. A driven headset scenario also clears it: walk to the car, press X, and the view stays.
