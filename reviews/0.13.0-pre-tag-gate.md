## Fix before the tag (verified majors)

- [ ] **Two scenes can leave every Babylon sound on the page muted** (correctness + blast-radius, confirmed). File: `src/tosi-b3d.ts:5831-5834`.
  - What happens: each `<tosi-b3d>` reads `AbstractEngine.audioEngine.getGlobalVolume()`, sets the volume to 0, and on reveal or teardown restores the value it read. Nothing counts holds across scenes, and the audio engine is one object for the whole page.
  - Failing order: A saves 1 and sets 0. B saves 0. A reveals and restores 1. B reveals and restores 0. Babylon audio then stays silent until reload.
  - Second failure: a volume the page sets while a scene is loading is overwritten at reveal.
  - Refuted part: the "one scene setting up twice" case does not happen. A same-task reconnect returns early, and teardown restores the volume first.
  - Fix: use the same pattern as `holdEffectAudio`. Keep one module-level set of holds. Read the volume when the first hold is taken and restore it when the last is released. Skip the restore if the volume changed in the meantime.
  - **Clears when:** a unit test takes two holds and releases them in build order (A then B) and then in the reverse order, checks the volume ends at its original value both times, and fails with the fix reverted.
- [ ] **Migration.md has no `0.12.x → 0.13.0` section** (docs, confirmed). File: `Migration.md:12`.
  - The CHANGELOG index tells a reader crossing a minor to start with Migration.
  - `riggedBodyGlb(body, { garments })` no longer bakes the cloth look. Before, `bake` defaulted to true; now it is `ClothBaker | false` and is off by default. Exports quietly lose their recolouring.
  - Dramatis, which the character builder serves, is the known consumer.
  - The section should list:
    - pass `bake: bakeClothLook` from `tosijs-3d/cloth-bake` to keep baked pictures
    - Slow motion is removed (set `timeScale` yourself)
    - barMenu submenus now cascade beside the list
    - viewMenu is hidden in a headset
  - Also put the riggedBodyGlb item in a **⚠️ Breaking** block on `changelog/v0.13.0.md`.
  - **Clears when:** the heading exists and covers these four items. This is a docs-only change.
